# Naturality of ordinary rank-selected cohomology

For each rank set S in a finite simplicial poset, the canonical comparison from reduced cohomology relative to the empty subposet to ordinary reduced cohomology intertwines every order automorphism. The comparison holds over a commutative ring in cohomological degree |S| − i − 1 for each natural number i. It identifies the ordinary cohomology action in Theorem 1.2.
