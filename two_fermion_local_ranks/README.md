# Local ranks and exterior Hilbert functions of two-fermion coinvariants

For separated paired two-fermion data over an algebraically closed field of characteristic zero, the dimension at each support point is a product of the ramification orders, cluster multiplicities and a power of two. The exterior Hilbert polynomial determines the dimension in each exterior degree. For a positive number of variables the global formulas give the corresponding dimensions in terms of the degrees of the input polynomials.

The four statements follow Theorem 7.2 in the paper. Each local dimension is computed on the localized quotient itself. The global rank and Hilbert formulas assume a positive number of variables. The proof and statement sources are listed in [the result map](map.json).
