# The cluster factors of separated two-fermion quotients

For each support point of separated paired data and each cluster at that point, its homogeneous cluster algebra is isomorphic to a paired two-fermion quotient with the inherited roots and ramification orders. The isomorphism preserves each exterior bidegree. The coefficient field is algebraically closed of characteristic zero.
