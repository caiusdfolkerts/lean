# Irreducibility of fixed higher Specht spans

The companion compares the fixed-span irreducibility clauses of the Springer and Griffin basis theorems in Theorems 1.1 and 4.1 and the corresponding characteristic-range extension of Corollary 8.1. The Challenge defines the spans of the actual quotient classes and the induced permutation action. The identification with the ordinary Specht module of the given shape remains outside this selection.
