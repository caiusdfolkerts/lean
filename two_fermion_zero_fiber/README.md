# The zero fiber of the type A two-fermion degeneration

For a positive number of variables over a characteristic-zero field, the specialization of the Rees algebra at zero is isomorphic as an algebra to the associated graded of the two-fermion quotient. The comparison sends each specialized Rees basis element to its graded class and commutes with the GL₂ action induced on filtration quotients.
