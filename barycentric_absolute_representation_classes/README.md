# The ordinary rank-selected cohomology formula for representation classes

For a finite simplicial poset with a group action and coefficients in any field, each homogeneous Koszul homology group has the same class in the Grothendieck group of finite-dimensional representations as the sum of the ordinary rank-selected reduced cohomology groups of the prescribed internal degree. The left side uses the coefficient complex relative to the empty subposet, whose homogeneous homology identifies equivariantly with the internal degree of ordinary Tor. On both sides the group acts by the given poset automorphisms.
