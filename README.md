# Shared finite subsets in reconstruction certificates

The two variants prove the existing `Nonrational.TerminalVerification.certified_B000` for all thirty targets. The baseline uses the compressed, numeric-token-corrected source candidate. The pooled variant replaces the 1,510 local subset declarations in the batch by names from the global table of 644 distinct labelled subsets used across all 4,664 ordinary reconstruction certificates. Each shared definition uses its exact original increasing vertex list and a kernel-checked proof of distinctness. The full face, incidence, priority, frame, height and coverage witnesses still elaborate, as do the thirty original target-equality arguments. [Upstream project](https://github.com/caiusdfolkerts/research/tree/e0696fddcd3d10b5d6461e62e9b2f02c4195be37/small_nonrational)

The ordinary diagnostic uses Lean 4.35.0 with its pinned Mathlib dependency. It builds identical prerequisites once, builds the two proof variants separately with kernel typechecking enabled, checks the exact endpoint type and measures their respective exported proof environments. The receipt distinguishes one-time literal-pool construction from each variant's batch and target-module costs. This experiment measures ordinary elaboration and export. Independent checker timings and the full Theorem 2 preflight are separate work.

Run `python3 diagnostic/run.py` for offline source validation. A push to `palomar/diagnostic-small-nonrational-projection-pool` starts the benchmark.
