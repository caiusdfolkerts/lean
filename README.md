# Indexed face witnesses in projection certificate batch 078

All three variants prove `Nonrational.TerminalVerification.certified_B078` with its original type for targets 2373 through 2402. The baseline batch module is the byte-exact upstream source. The second variant shares the 644 global ten-vertex subsets. The third additionally obtains every explicit facet or polygon witness by its original position in the literal face list, using Lean's list membership theorem. The actual face sets and all frame, priority, incidence, height, coverage and target-equality arguments remain. This batch uses explicit facial witnesses, as do 155 of the 157 original batches. It contains 1,530 local subset declarations and 1,052 such face references.

The standard runner compiles the common prerequisites once and each variant separately. It verifies the exact named theorem type and records ordinary kernel compilation costs and exported proof size, declaration count and axioms. The shared dictionary is built once per pooled variant and its cost is reported separately. The experiment uses raw upstream batch source for all three transformations so the comparisons isolate the mathematical changes. The remaining common project prerequisites use the candidate's hash-pinned source. Independent kernel timings are outside this bounded diagnostic.
