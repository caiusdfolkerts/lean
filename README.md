# Sharing literal cell proofs

Each graph record currently checks its literal edge list, ten vertex incidences and all 45 missing-edge bits at every selected slot. Across the 35,119 records, this performs 149,663,880 missing-edge pair checks. There are 16,437 distinct selected tuples, requiring 739,665 such checks if each tuple receives one reusable proof. These counts cover one condition only.

The proposed bridge checks a tuple's true edges and missing-edge mask once and uses those facts at each of its selected slots. Four independent fixed-width slot alignments identify the cell, edge list, edge mask and missing mask. A proof by bit extensionality gives the selected field after packing commensurate slots. Width obligations remain explicit for all cells. For vertex incidences, one exact matrix equality per record invokes the existing sparse-matrix row theorem. A separate Bool checks the original geometric frames, root emptiness and every original terminal. The resulting theorem proves the existing sideCheck equality and is intended for the unchanged completeBlock call.

PackedSlot.lean contains the generic fixed-width selection proof. TupleLiteralSharing.lean defines checked tuple facts, the vertex matrix transport and the final sideCheck theorem. SharedRecord.lean ties packed coordinates and per-tuple facts to the record. These three modules are drafted, with elaboration and concrete replay pending. The previous accepted sample used direct literal checking. The new bridge's runtime benefit depends on its normalization costs and on which original checks dominate full replay.

The measurement reader counts every top-level exported expression record and its expression constructor in both data-only exports, the generic proof, and the final endpoint. Only bounded aggregate counts enter the receipt.
