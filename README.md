# Three residual graph blocks for small nonrational four-polytopes

This source-only diagnostic checks three original, disjoint compact graph intervals. Block 0528 covers 18 row-29 keys with quota and matching leaves. Block 0824 covers three row-31 keys, including a vertex-link exclusion. Block 1055 covers the final 26 keys of row 32 in the six-facet universe. The joint theorem takes the conjunction of their exact public endpoints.

A standard Ubuntu runner compiles the exact reachable sources with Lean 4.35.0. It exports the generic soundness theorem, each block separately, and their combined proof with the same primitive targets. These measurements reveal which exported declarations are shared. The workflow then runs Lean's kernel, NanoDa and verified con-ron on the joint export. Each phase saves a bounded JSON receipt. Proof exports and compiled files remain ephemeral. The source map retains the original typed match and frame witnesses and the full original interval types. [Original repository](https://github.com/caiusdfolkerts/research/tree/e0696fddcd3d10b5d6461e62e9b2f02c4195be37/small_nonrational)

The push branch is `palomar/diagnostic-small-nonrational-family`. Use `python3 diagnostic/run.py replacement` for offline source/hash verification. The input pins and provenance are in `diagnostic/manifest.json`. The lower-bound submission requires a separate complete Palomar preflight.
