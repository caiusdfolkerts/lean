# Lean

This repo is home to the Lean formalisations for all my mathematics research. I've tried to make it as self-explanatory as possible. If you want to contact me, email me at caiusdfolkerts@gmail.com. 

You'll need to install Elan and Git to run the verification. 

| Project | Flagship result |
| --- | --- |
| [`alternating_forms`](alternating_forms/) | We determine the Hilbert series of a complex exterior algebra modulo two general quadrics in every dimension. |
| [`barycentric_invariance`](barycentric_invariance/) | Barycentric subdivision preserves the face ring of a finite simplicial poset as a module over its universal parameters. |
| [`bier`](bier/) | We construct the first explicit nonpolytopal Bier spheres. |
| [`cold_spots`](cold_spots/) | The deep holes of E₈ and several related lattices minimize every Gaussian lattice sum. |
| [`conditional_decomposability`](conditional_decomposability/) | A conditionally Minkowski decomposable $d$-polytope needs at least $4d-4$ vertices, and this is sharp for every $d\ge3$. |
| [`cubical_lower_bound`](cubical_lower_bound/) | We prove Jockusch’s conjecture that stacked cubical polytopes minimize every face number for their dimension and vertex count. |
| [`deformed_coinvariants`](deformed_coinvariants/) | We prove the Hivert–Thiéry conjecture. |
| [`ellipsoid_intrinsic_volumes`](ellipsoid_intrinsic_volumes/) | The intrinsic volumes of an ellipsoid determine its semiaxes in every dimension. |
| [`two_fermion_coinvariants`](two_fermion_coinvariants/) | Two-coloured lattice paths index monomial bases for the two-fermion coinvariant rings of types A and B. |
| [`homological_shifts`](homological_shifts/) | We give a partition formula for the rank of every homological shift ideal of a polymatroidal ideal. |
| [`clique_covered_rigidity`](clique_covered_rigidity/) | Every six-connected graph whose edges lie in copies of $K_4$ is generically rigid in three dimensions. |
| [`mixed_volume_realization`](mixed_volume_realization/) | It is undecidable whether prescribed rational numbers are the mixed volumes of 44 convex bodies in three dimensions. |
| [`normal_projective`](normal_projective/) | A combinatorial $d$-cube can be brought to the standard cube in $2d-3$ normal or projective moves, and this bound is sharp for $d\ge2$. |
| [`polymatroidal_ideals`](polymatroidal_ideals/) | A monomial ideal is polymatroidal if and only if every monomial localization has a linear resolution. |
| [`projection_areas`](projection_areas/) | Four-coordinate inequalities characterize coordinate projection areas in dimension four and cease to suffice in every higher dimension. |
| [`toric_quadratic_generation`](toric_quadratic_generation/) | A smooth lattice $d$-polytope with all edges of lattice length at least $d$ is normal and has a toric ideal generated by quadrics. |
| [`rank_three_projection_volumes`](rank_three_projection_volumes/) | For $n\ge5$, no positive hollow matrix of rank three is a limit of coordinate codimension-two projection volumes of convex bodies in $\mathbb R^n$. |
| [`higher_specht_bases`](higher_specht_bases/) | We construct higher Specht bases for every Springer and Δ-Springer ring in characteristic zero. |
| [`three_sunlet_models`](three_sunlet_models/) | For a finite abelian group of order $m\ge5$, the three-sunlet model has dimension $5m-4$ in every characteristic. |
| [`symmetric_rank_conditions`](symmetric_rank_conditions/) | The prescribed minors of a symmetric northwest rank profile form a Gröbner basis for the folded antidiagonal order over every field. |
| [`volume_polynomials`](volume_polynomials/) | We solve the Heine–Shephard problem by characterizing volume polynomials through coefficient nonnegativity and an explicit family of quadratic inequalities. |
| [`graphical_zonotopes`](graphical_zonotopes/) | An indecomposable generalized permutahedron of dimension $n-1\ge3$ has at least $3n-6$ edge directions, and this bound is sharp. |
| [`sublattice_resolutions`](sublattice_resolutions/) | For ideals with sublattice initial ideals, equality of Betti numbers with the initial ideal in the first power forces equality in every power. |
| [`cubical_indecomposability`](cubical_indecomposability/) | We disprove Smilansky’s conjecture by constructing a Minkowski indecomposable four-polytope whose facets are all combinatorial cubes. |
| [`unimodular`](unimodular/) | Integral facet equations and a single degree condition characterize the complete fans on a uniformly unimodular ray configuration. |
| [`singular_vector_spans`](singular_vector_spans/) | We classify all singular-vector span defects for generic tensors one step beyond boundary format. |
| [`stress_flex`](stress_flex/) | Strong stress–flex orthogonality holds for every coned polyhedral sphere in three dimensions and fails for an explicit nine-vertex torus. |
| [`small_nonrational`](small_nonrational/) | The minimum number of vertices of a four-polytope with no rational realization lies between 11 and 17. |
| [`wishart`](wishart/) | We prove the Wishart product conjecture of Genest, Ouimet and Richards for any number of disjoint principal minors. |
| [`toric_power_maps`](toric_power_maps/) | We prove the Hanlon–Hicks–Lazarev conjecture on Frobenius generation for line bundles on smooth complex toric varieties. |
