# First strands and minimum-generator Tor injections

Corollary 5.3 of *Sublattice resolutions and Betti preservation in all powers*: a nonzero positive homological strand occurs by the homological degree, and multiplication by the minimum row monomial injects the actual Tor groups of successive powers. For a homogeneous deformation satisfying the original first-power Betti comparison, the same holds for its specified corresponding homogeneous generator, with any nonzero leading coefficient.
