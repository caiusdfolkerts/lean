# Rank-selected relative cohomology

For a finite simplicial poset and a downward subposet, each bigraded piece of relative barycentric homology is linearly equivalent to the product of the reduced cohomology groups of the rank-selected pairs. The indices have prescribed total degree and weight, and the cohomological degree for a rank set S is |S| − i − 1. This gives the cohomology factor in the relative formula of Theorem 1.2 over a commutative coefficient ring.
