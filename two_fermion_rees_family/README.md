# The flat Rees family of type A two-fermion coinvariants

Over a characteristic-zero field and for a positive number of variables, the strict multiplicity filtration determines the Rees algebra coefficient by coefficient. This algebra is finite, free and flat over the polynomial parameter ring. The GL₂ action on the family acts on each Laurent coefficient by the color action on the original quotient.
