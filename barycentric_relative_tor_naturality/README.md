# Naturality of the homogeneous inclusion in relative Tor

For a finite simplicial poset and a downward closed subposet, the canonical map from each homogeneous relative Koszul homology group into ordinary derived Tor is injective. Every order automorphism preserving the subposet acts compatibly with this inclusion. These two results identify the action on each internal degree of Tor in Theorem 1.2.
