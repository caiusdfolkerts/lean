# Graded characters of higher Specht quotients

These assertions express the graded Frobenius clauses of Corollaries 5.3, 5.6 and 6.7 as equalities of characters. For each degree the left side is the trace of the actual action on the homogeneous piece of the quotient by the displayed ideal expression. The right side uses the ordinary Specht character of the indicated shape for each eligible index in that degree. Applying the Frobenius characteristic map sends each such character to the Schur function of that shape.
