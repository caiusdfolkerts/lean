# Nonzero fibers of the type A two-fermion degeneration

Over a characteristic-zero field, for every positive number of variables and every nonzero parameter, the specialized Rees algebra is isomorphic to the original two-fermion quotient. Both the general nonzero specialization and the specified comparison at one intertwine the GL₂ color action.
