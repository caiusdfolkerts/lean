# The associated graded algebra and exterior blocks of two-fermion coinvariants

Over a characteristic-zero field, for a positive number of variables, the associated graded two-fermion algebra is isomorphic to its initial quotient and decomposes linearly into admissible exterior coefficient blocks. The algebra comparison identifies each graded basis class with its initial representative. The block coordinates are specified on polynomial–exterior tensors, and the block decomposition intertwines the induced GL₂ action on all elements.
