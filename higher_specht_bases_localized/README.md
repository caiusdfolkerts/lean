# Localized higher Specht bases

This companion formalizes the Springer and Griffin localized basis clauses of Corollary 8.1. The Griffin version assumes the diagram size is at most the ambient number of variables, the exponent bound is positive, and the diagram height is at most that bound. The Springer version applies to every diagram.

The Challenge defines the prescribed families independently. The Solution exposes the original proofs from higher_specht.verified.remaining03_coefficients. The comparison includes the supporting facts required by the literal tableau definitions.

The core basis and exact characteristic statements are recorded at commit fb5ab9354a764e61ae08d5e8f631614d1920f776. See map.json for precise declarations.
