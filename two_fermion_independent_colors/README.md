# Independent color changes on the initial two-fermion quotient

For the type A two-fermion quotient over a characteristic-zero field in a positive number of variables, each index admits an independent GL₂ change of exterior colors. The induced action on the initial quotient agrees with the change on ambient representatives. The canonical comparison with the direct sum of admissible exterior coefficient blocks intertwines these actions.
